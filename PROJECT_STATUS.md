# Project Status — bitchat-android

**Portfolio class:** Engineering lab / Android  
**Maturity:** **Software prototype**

This is an authored Android communications experiment exploring Kotlin, Jetpack Compose, BLE GATT/store-and-forward concepts, coroutines and modern Android permission/state handling.

## Evidence boundary

Cryptographic primitives and secure-messaging concepts in this repository are application experiments, not evidence of an independently audited cryptographic protocol or production-secure messenger.

The separate `bitchat` repository is an upstream research fork and is not represented as authored MAZLABZ work.

**Portfolio use:** native Android + BLE/P2P architecture evidence.
